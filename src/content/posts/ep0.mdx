### 📕 Shownotes

这里是 AsyncTalk，一档面向对 Web 开发感兴趣的朋友所录制的中文播客。第 0 期并不展开某一个具体技术，而是由主播介绍这档节目的创办背景、关注方向，以及准备长期做下去的目标：和我们一起，将 Web 开发带向下一个高度。

如果你是第一次听到 AsyncTalk，可以把这一期当成入口。节目希望和听众一起把 Web 开发往前推进一步，后续会讨论更多更前沿、更偏工程化的话题。感兴趣的话，可以从这一期开始认识节目，再按时间把后面的内容听下去。

这一期的主播是 AnnatarHe、sleaf、Tinko 和 小鹿。节目标记的分类是 technical、web 和 hacker，对应节目一开始就想覆盖的范围：技术本身、Web 开发，以及动手解决问题的方式。它在节目信息里是一则 trailer，发布于 2021 年 10 月 14 日，作为第一季的第 0 期，用来说明 AsyncTalk 为什么存在、准备跟谁聊，以及之后会把时间花在什么样的内容上。有话说可以直接写信，地址就留在这一页的链接里。

### 本期要点

- 节目定位是面向 Web 开发者的中文播客，第 0 期用来认识 AsyncTalk
- 主播介绍创办背景和关注方向，而不是完成一次专题讨论
- 长期目标和网站上的那句话一致：将 Web 开发带向下一个高度
- 后续内容会继续走向更前沿、更工程化的话题
