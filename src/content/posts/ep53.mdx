### 📕 Shownotes

Claude Code 火起来之后，终端里的用户界面又一次被很多人看见。这一期就从这件事谈起：TUI 带着比以前强得多的上下文回到主流视野，也立刻引来另一拨评价——有人觉得这是过时的技术，是在开倒车。标题用一个更口语的问法把争议说完：「TUI 是老登技术吗？」

节目要回顾的是 TUI 的优势、限制和交互特征，再讨论它到底是一段已经被图形界面淘汰的旧路，还是 AI 时代一个新的入口。文字部分没有把某一种界面宣布为赢家。它把两边的说法放在一起：一边是「老、不中用、在倒车」，另一边是它这次回来时手里多了强大的上下文，使用方式和当年纯靠快捷键的终端工具已经不一样。

分类记的是 tui 和 programming，主播是 AnnatarHe。结尾留了两句歌词，当作这一问的注脚，而不是技术结论：

Ah, but I was so much older then
I'm younger than that now

如果你最近才因为 Claude Code 重新打开终端，这一期适合用来给 TUI 这次回潮一个位置：它强在哪里、卡在哪里、交互上长什么样，以及「老登技术」这个标签公不公平。

### 本期要点

- Claude Code 爆红之后，TUI 重新进入主流讨论
- 这次回来时，它带着强大的上下文
- 反对意见：过时、开倒车、不中用
- 节目回顾 TUI 的优势、限制和交互特征
- 问题收在一个选择上：旧技术，还是 AI 时代的新入口
- 分类：tui、programming
