### 📕 Shownotes

AI 进入日常写代码之后，做法本身变了，而且变得很彻底。这一期从 Next.js、Tailwind CSS 和 Node.js 的项目实践出发，谈怎样少做那些并不能帮你交付的技术选择，把注意力放回交付、约束，以及一套可维护的默认方案。标题用「丢掉大脑才能写好代码」来形容这种转变：不是真的不再思考，而是别把精力耗在每一个可选项上。

节目给出的默认组合是 Next.js、Tailwind CSS 和 Node，用来把项目搭起来。集成别人的库时，优先选 star 数高的那些。代码这边强调可读性，也明确说不要过度优化。比工具名单更靠前的是思维：AI 把个人能完成的事情放大了很多，于是更需要的是创造力和热情，而不是再增加一轮无休止的方案比较。

分类覆盖 ai、nextjs、tailwind 和 programming，主播是 AnnatarHe。可以把这一期听成一份「先用什么、先不纠结什么」的说明。它推荐的是上述这套默认栈和高星项目，讨论的是减少无效选择；没有在文字里展开更多未点名的框架。

### 本期要点

- AI 时代写代码的方式已经明显改变
- 从 Next.js、Tailwind CSS 和 Node.js 的实践谈起
- 减少无效的技术选择，回到交付、约束和可维护的默认方案
- 集成时选择 star 数高的库
- 可读性重要，不要过度优化
- 思维要跟着变：个人能力被放大之后，创造力和热情更关键
