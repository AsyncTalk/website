### 📕 Shownotes

Grok Bot、Meta 的 Muse、OpenAI 的 Dots，还有 Claude 正在内测的 Duet，Personal Agent 接连登场。有人说它只是又一个昙花一现的玩具，但在我看来，它是改变我们生产方式的一道分水岭。

**这期聊了**

- **Personal Agent 是什么**：一个私人助理，帮你记着明天和谁开会、后天去哪出差、哪天带孩子打疫苗
- **和 OpenClaw 的区别**：不再只是在 server 上发请求，而是在云端有一台电脑，通过 Computer Use 像人一样打开网站、选日期、比价格、下单
- **生产方式的分水岭**：从拿本子记账，到用网站和 App 记录，再到直接丢给 AI
- **为什么很多人没意识到它的潜力**：Computer Use 是最关键的能力，国产模型还有进步空间；Memory、上下文检索和中间那层 Harness 也都很难做，目前做得好的是 Claude Code 和 Codex
- **国内外生态**：海外产品各自独立、开放接入，人人都能接 Gmail 的 Connector；国内产品分属不同的大体系，彼此之间有壁垒
- **释放全部能力之后**：我的判断是短期内会有一半以上的人失业。我朋友已经把合规申报、填发票报销单这类工作丢给了 Grok Bot
- **实例：我的 Grok Bot**：每个项目一个 Manager。Echo 管 AsyncTalk 的大纲、字幕和官网，Penny 回答金融问题，Shelton 打理 ShellTime
- **它还不完美**：Token 用量会飞起来，网页拦截、权限控制、付款信息都还没有好的解决方案

**模型能力是一切吗？**

模型是基础，但我不同意"模型能力就是一切"。Anthropic 发布 Claude Fable 5.1 和 Mythos 5.1 时，展示了绘制金星高程图、设计蛋白结合剂，这样的突破只有少数人能直接受益。能帮你买菜做饭的 AI 反而更应该发展：每件琐事帮你省 30 分钟，一天省下两三个小时，就能多陪陪家里的狗和孩子。Personal Agent 是让每个普通人都真正用上 AI 的新起点。

如果各个体系、各家公司之间的壁垒取消了，你会让 Personal Agent 帮你做什么？欢迎在评论区聊聊。
