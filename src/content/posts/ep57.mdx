### 📕 Shownotes

曾经有一段时间，Cursor 这种把 AI 嵌进 IDE 的混合模式，看起来就是接下来写软件的方向。这一期把这个判断翻过来：方向已经清楚了，不开代码、不直接盯着编辑器，才是接下来写代码的方式。标题用一句玩笑把三角关系说完——Cursor 别来联系我，免得 Claude 和 Codex 误会。

节目从 Cursor 的 AI IDE，转到 Claude Desktop 和 Codex App，讨论一种不直接打开代码的 Agent 工作流，为什么有可能代表软件开发的下一阶段。文字里点到的条件有四样：不必打开代码，可以做多仓库协作，接得上完整的 CI/CD，以及用 Plan Mode 先做规划。当这几样放在一起，它可能才是以后的开发模式。这里的「可能」留在节目自己的说法里，没有被写成已经发生的替换。

分类是 ai 和 programming，主播是 AnnatarHe。这一集是第三季的第 57 期，发布于 2026 年 3 月 10 日。适合正在 IDE 里用 AI 补全、又开始试桌面端 Agent 的人听。这一期比较的是工作流的形态：人还要不要把代码文件打开，规划、跨仓库和流水线要不要交给同一套 Agent，而不是比较编辑器的快捷键。小宇宙、YouTube 和 Bilibili 都能打开同一期。

### 本期要点

- 曾经以为 Cursor 这类 AI 加 IDE 的混合模式会是未来
- 现在的判断：不打开代码，才是接下来写代码的方式
- 转到 Claude Desktop 和 Codex App 来看这种 Agent 工作流
- 点名的能力：不必打开代码、多仓库协作、完整 CI/CD、Plan Mode
- 讨论它为什么可能是软件开发的下一阶段
